# Soren Hale — Light Portfolio

A light-mode developer portfolio built with Next.js (App Router), TypeScript and Framer Motion.

## Run it

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # production build
```

## Customize

- All text, projects, scores, stack, career and reviews live in `components/data.ts` (sample content).
- Colors are CSS variables at the top of `app/globals.css` (`--bg`, `--ink`, `--lime`, ...).
- Replace the placeholder portrait SVG in `components/Hero.tsx` with your own photo.
- The contact form opens the visitor's email app with the brief filled in. Change the address in `data.ts`.
